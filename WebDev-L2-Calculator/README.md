# Calculator Web Application

## Overview
A responsive calculator web application developed as part of the Oasis Infobyte Web Development and Designing Internship.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Addition, subtraction, multiplication, and division
- Clear and delete functions
- Decimal number support
- Simple and responsive user interface

## Project Structure
- `index.html` – Defines the calculator structure
- `style.css` – Styles the calculator interface
- `script.js` – Handles calculator operations

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Alternatively, use the Live Server extension in Visual Studio Code.
