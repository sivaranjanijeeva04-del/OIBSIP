
# TaskFlow - To-Do Web App

## About
TaskFlow is a simple and responsive To-Do List web application built to help users organize and manage their daily tasks.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Features
- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Filter all, pending, and completed tasks
- View task summary counts
- Save tasks using localStorage
- Responsive design for mobile and desktop

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server, or open it directly in a browser.
4. Add, edit, complete, and delete tasks.
