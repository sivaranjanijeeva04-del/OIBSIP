
# SecureSpace - Login Authentication System

## Project Overview
SecureSpace is a responsive login and signup web application developed as part of the Oasis Infobyte Web Development and Designing Internship, Level 2.

## Features
- User registration and login
- Email validation
- Password strength validation
- Confirm password validation
- Show and hide password
- Dashboard after successful login
- Logout functionality
- Session handling
- Responsive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Local Storage
- Session Storage
- Web Crypto API

## Project Structure
- `index.html` - Application page structure
- `style.css` - Styling and responsive design
- `script.js` - Form validation and demo authentication logic
- `Login_Page.png` - Login page screenshot
- `Signup_Page.png` - Signup page screenshot
- `Dashboard.png` - Dashboard screenshot

## How to Run
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Run `index.html` using Live Server.
4. Create an account and test the login and logout functionality.

## Security Note
This is a frontend learning project. It is not production-ready authentication. Real applications require secure backend authentication and server-side validation.
