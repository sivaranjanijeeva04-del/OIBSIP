
# Dr. APJ Abdul Kalam Tribute Page

## About
A responsive tribute website dedicated to Dr. APJ Abdul Kalam, India's Missile Man and former President.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Responsive navigation
- Biography and life timeline
- Achievements cards
- Books section
- Interactive inspirational quotes
- Mobile-friendly layout

## How to Run
Open `index.html` in a browser or use VS Code Live Server.
